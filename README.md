# verna-software-guidelines

**Verna Software Guidelines (VSG)** is the official reference for clean code, development standards, and team-wide best practices.  
It focuses on modern C++/Qt, Git workflows, consistency, readability, and collaborative engineering habits.

## 📚 Sections

- C++/Qt Development Guidelines
- Clean Code & Naming Conventions
- Modern C++ Practices (RAII, Rule of 5, Smart Pointers)
- Qt Best Practices (Signals, QObjects, QML, MVC)
- Git Workflow & Commit Standards
- CI/CD & Testing Strategy
- Documentation Standards

## 📁 Structure

All documentation is organized under the `docs/` directory and grouped by topic. Each section contains focused `.md` files for clarity and ease of maintenance.

## 🛠 How to Use

Clone the repository and browse the `docs/` folder.  
You can open `.md` files directly in any Markdown viewer or integrate them with a static site generator like **MkDocs**.

```bash
git clone https://github.com/verna-software-guidelines/vsg.git
cd vsg/docs
